###   BREAKING CHANGES

* **economy:** found villages from winter conservation losses
* **engine:** guarantee a viable starting position and forces
* **engine:** Army.Starving changes the state.json contract; no compatibility with existing games is required per specs/economie.md.
* **mapgen:** densify villages for the new economy
* **economy:** fortify a village with C C instead of replacing it
* **engine:** make territorial control ephemeral outside fiefs
* **economy:** make fief control transitive and route income to the fief capital
* **economy:** existing games resolve mill production differently.
* **economy:** pay territory income to the capital
* **economy:** balance keys infra_rations_bonus, bonus_mill_production and bonus_army_ration are rejected; existing games resolve differently.
