Brief d'exécution autonome pour un modèle d'implémentation.

## Contexte

Backend Go P0.1/P0.2 en place (`cmd/server`, assets CSV chargés). Le dossier
`web/` ne contient qu'un `README.md` placeholder (« Not yet scaffolded: it
arrives in task P0.3 »). Node v22.23.1 / npm 10.9.8 disponibles (compatibles
Vite 7). Le prompt source est `specs/prompts/p0.3-scaffold-front.md` — le lire
en entier avant de commencer. Références : `specs/architecture.md` (section

Règles absolues :

- Code exclusivement en anglais (identifiants, fichiers, commentaires, valeurs
  d'enums) ; seules les chaînes de **contenu de jeu** (noms de territoires,
  libellés UI affichés au joueur) sont en français.

- Ne rien commiter.

## Difficulté et modèle recommandé

Difficulté **3/5** — le scaffolding est piloté par CLI mais piégeux : Tailwind
v4 (pas de fichier de config, config CSS uniquement), `shadcn init` exigeant
les alias `@/` dans trois fichiers (tsconfig + vite), fusion avec le template
Vite dans un dossier non vide (`web/README.md`). La seule vraie difficulté de
code est le **pan/zoom SVG ancré au curseur** (React attache `wheel` en passif
→ nécessite un handler non-passif via `ref`) et les **fixtures géométriques
cohérentes** (adjacences symétriques, degré ≥ 2, polygones jointifs).
Modèle conseillé : milieu de gamme type Claude Sonnet 4.5
(`anthropic/claude-sonnet-4.5`) — coût estimé < 0,15 €. Budget acceptable :
Kimi K2 (`moonshotai/kimi-k2`) avec vérification renforcée des étapes 1-3
(les pièges de versions y vivent).

## Étape 5 — Fixtures (web/src/fixtures/)

### `map.ts` — 12 territoires, grille 4×3 (viewBox 640×480, cellules 160×160)

- Chaque territoire = polygone convexe irrégulier de 5-7 points, dessiné à la
  main autour du centre de sa cellule (pas de Voronoï). Les bords de cellules
  voisines doivent coïncider **approximativement** (petits écarts tolérés à
  v0 : le stroke les masque). Un exemple de points partagés au niveau des
  nœuds de grille simplifie la jointure.
- Répartition terrains (les 5 présents) : 3 `plain`, 3 `forest`, 2 `hill`,
  2 `mountain`, 2 `swamp`.
- Lieux-dits : **3 sur 12 (25 %)** → codes 3 lettres = trigrammes de communes
  des assets (`ROS` Rosemont, `VIL` Villeneuve, `GRI` Griffecourt), noms en
  français, `lieuDit: true`.
- Non lieux-dits : codes 4 lettres = préfixe réel de `qualificatifs.csv` +
  trigramme d'une commune **adjacente** (ex. `FROS` Forêt de Rosemont,
  `MVIL` Monts de Villeneuve, `CGRU` Collines de Griffecourt…). Varier les
  préfixes (F/M/C/P/A/H/B/V/L/R).
- `adjacencies` : symétriques (si T01 liste T02, T02 liste T01), degré ≥ 2
  partout, correspondant aux frontières réelles de la grille (voisins
  horizontaux/verticaux/diagonaux, au choix selon la forme des polygones).

### `state.ts` — vue du joueur P1

- `turn: 12`, `season: "autumn"`, `asOf` : majorité des territoires à `12`,
  **3-4 territoires à 9/10/11** (fraîcheur stale visible sur la carte).
- `territories` : les 12 entrées avec `owner` = `"P1"` / `"P2"` / `null`
  (répartition ~5 P1, ~4 P2, ~3 sauvages) ; `resources` présents sur les
  lieux-dits (4-6) ; armées : `A1`/`A2` (P1) sur 2 territoires, `A3`/`A4`
  (P2) sur 2 territoires ; infrastructures : un `mill` level 2 (P1), un
  `castle` sur le lieu-dit de départ de P1, un `castle` sur celui de P2.
- `nobles` : `N1` Hugues (P1, sur un territoire P1), `N2` Renaud (P2, sur un
  territoire P2).

## Étape 6 — Composant MapViewer (web/src/components/MapViewer.tsx)

- Props : `{ map: MapData; state: StateData; onSelect?: (id: string) => void }`
- **Généricité** : aucune référence en dur aux fixtures ni aux ids `P1`/`P2` ;
  les couleurs joueurs sont dérivées des owners présents dans `state`
  (owners triés → palette interne à indexer).
- État interne : `view { x, y, k }` (pan + zoom), `selectedId`.
- Helpers : `pointsToPath(points)` → `M x,y L … Z` ; `centroid(points)` =
  moyenne des points (suffisant pour des polygones convexes à la main).
- Palette terrains (prompt) : plaine = vert clair, forêt = vert foncé,
  colline = marron, montagne = gris, marécage = bleu-vert.
- Rendu : conteneur `relative w-full h-full overflow-hidden` + SVG 100 %
  (`viewBox="0 0 640 480"`, `touch-action: none`) ; un `<g>` transformé
  `translate(x, y) scale(k)` contient les couches :
  1. **Fond** : un `<path>` par territoire, `fill` = couleur du terrain,
     `stroke` fin.
  2. **Fraîcheur** : si `asOf[id] < turn`, path overlay `fill="black"`
     opacité ~0.3 (assombrissement léger) — prépare la vision T-x.
  3. **Couche vivante** : marqueurs d'armées (cercle r≈6 coloré par joueur,
     décalé du centroïde), icônes d'infrastructures en **primitives SVG**
     (pas d'emoji : petit carré crénelé pour château, croix de pales pour
     moulin), ressources « ×N » sur les lieux-dits, pictogramme lieu-dit
     (petite maison triangle+carré), marqueur de noble (losange doré) aux
     emplacements des `nobles` de `state`.
  4. **Labels** : trigramme (`code`) au centroïde, `pointer-events="none"`.
- Sélection : `onClick` sur les paths → si pas de drag, `setSelectedId` +
  `onSelect(id)` ; territoire sélectionné = contour surligné (stroke épais
  ambré).
- Pan/zoom :
  - Roulette : handler `wheel` attaché via `ref` + `useEffect` avec
    `{ passive: false }` (React attache `onWheel` en passif → `preventDefault`
    impossible → la page scrollerait). Zoom clampé `[0.5, 4]` **ancré au
    curseur** : `t' = cursor - (cursor - t) × (k'/k)` (cursor en coordonnées
    du SVG via `getBoundingClientRect`).
  - Drag : `onPointerDown` + `setPointerCapture`, `onPointerMove`, `onPointerUp`
    ; seuil de mouvement ~4 px pour distinguer drag (pan) de clic (sélection)
    via un flag `dragged` ; curseur `grab`/`grabbing`.
- Tooltips : shadcn `Tooltip` par territoire (`TooltipTrigger asChild` sur le
  groupe/chemin) — contenu : nom complet + terrain (libellé français) + si
  stale « Données du tour X ». Si le positionnement sur éléments SVG est
  capricieux, repli : `<title>` natif SVG.
- Légende : Card shadcn **flottante** (absolute, coin bas-gauche du conteneur)
  : pastilles des 5 terrains + libellés français (Plaine, Forêt, Colline,
  Montagne, Marécage) + note « Territoire assombri = données anciennes ».
