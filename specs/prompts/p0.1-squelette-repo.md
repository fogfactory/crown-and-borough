# Prompt P0.1 — Squelette du repo Go

```
Tu travailles sur "Crown & Borough", un jeu de stratégie asynchrone en Go (backend)
avec front React (ajouté plus tard). Le repo est neuf (vide à part specs/ et LICENSE).

Tâche : initialiser le squelette du projet backend Go.

RÈGLE DE CODE : le code est EXCLUSIVEMENT en anglais (identifiants, noms de
fichiers, commentaires, messages d'erreur/log). Seules les chaînes de contenu
de jeu (noms de communes, prénoms, qualificatifs, labels UI) sont en français,
langue du jeu.

1. Structure de dossiers (Standard Go Project Layout) :
   cmd/server/            # Main entrypoint (HTTP server minimal qui répond 200 sur /healthz)
   internal/api/          # Handlers HTTP, middleware, routes (vide pour l'instant)
   internal/engine/       # Moteur de jeu pur (vide pour l'instant)
   internal/db/           # Modèles SQL (vide pour l'instant)
   internal/models/       # Structures métier (vide pour l'instant)
   web/                   # Front React (dossier vide avec un README placeholder, ajouté plus tard)
   assets/                # Données statiques CSV (vide pour l'instant)

2. go.mod : module github.com/fogfactory/crown-and-borough, Go 1.22+.
   Le main de cmd/server doit juste exposer un healthcheck HTTP 200 sur /healthz.

3. Makefile avec cibles : build, run, test, vet, clean.

4. Dockerfile multi-stage :
   - Étape 1 : build Go (golang:alpine) → binaire statique
   - Étape 2 : conteneur final scratch ou alpine (~15 Mo)
   - L'étape de build front (web/) sera ajoutée dans une tâche ultérieure :
     laisse un commentaire clair à l'emplacement prévu.

5. CI GitHub Actions (.github/workflows/ci.yml) : sur push/PR vers main,
   exécuter go vet, go test ./..., go build ./... et le docker build.

6. .gitignore adapté (Go + Node, sans committer les binaires ni node_modules).

Critères d'acceptation :
- make build produit un binaire exécutable
- make run démarre le serveur ; curl localhost:8080/healthz renvoie 200
- make test passe (avec au moins un test trivial pour le healthcheck)
- CI verte sur le repo (si pushable) ; sinon démontrée localement
- Aucune dépendance tierce sauf justifiée (router chi réservé à une tâche ultérieure)

Ne commite pas : je m'en charge.
```
